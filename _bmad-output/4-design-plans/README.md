# 4 — Design Plans

**Design notes written before building** — the reasoning, the rejected alternatives, the agreed
approach. Less formal than a spec: a plan argues *why*, a spec defines *what*.

These are **inputs, not work items**, and several describe work already shipped. Do not read a
plan as a todo list — check [../2-current-work/open-items.md](../2-current-work/open-items.md)
for what's actually open.
